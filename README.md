# Transport Project

โปรเจกต์นี้เริ่มใหม่จากศูนย์สำหรับสร้างเกมขนส่งบนเว็บ โดยพัฒนาบนเกมหลักบน `main` โดยตรง **ไม่มี workflow ที่บังคับให้ผู้ใช้ต้องเปิด Pull Request, merge หรือกดดำเนินการเอง**

## ระยะเริ่มต้น

- UI/UX หลักของเกม
- **แผนที่กริดไม่มีขอบเขต (Infinite Grid)** — ไม่มีการล็อกเป็น 120 × 80 หรือขนาดโลกตายตัว
- ระบบจะวาดเฉพาะช่องกริดที่อยู่ในจอ เพื่อให้ขยายพื้นที่ได้โดยไม่ต้องสร้างช่องทั้งหมดไว้ล่วงหน้า
- Responsive สำหรับมือถือ แท็บเล็ต และจอใหญ่ รวมถึง Browser Zoom, split-screen และการหมุนจอ
- Canvas ปรับตาม viewport และพยายามรักษาจุดที่ผู้ใช้กำลังมองอยู่เมื่อ viewport เปลี่ยน
- Zoom 5%–300% โดยยึดตำแหน่งเมาส์
- ลากแผนที่, mouse wheel, touch drag และ pinch-to-zoom
- ปุ่มศูนย์กลางสำหรับกลับมาที่จุดกำเนิดของแผนที่
- เลือกช่องและอ่านพิกัดที่เป็นบวก/ลบได้
- เปิด/ปิดเส้นกริดและกริดหลัก

## ระบบถนน

ฐานถนนตอนนี้ไม่ได้เป็นเพียงเส้นที่วาดลงบน Canvas แต่แยกเป็น **road model + network topology** เพื่อให้ระบบรถในอนาคตใช้ข้อมูลชุดเดียวกัน

### ประเภทถนน

- 2 เลนสวนทาง — 1 เลนต่อทิศทาง
- 4 เลนสวนทาง — 2 เลนต่อทิศทาง
- ทางเดียว 1 เลน
- ทางเดียว 2 เลน
- ทางเดียว 3 เลน

ทางเดียวจะมีทิศตามลำดับจุดที่สร้าง และแสดงลูกศรบนผิวถนน

### การสร้างถนน

1. เลือก **สร้างถนน**
2. เลือกชนิดถนน
3. แตะ/คลิกจุดแรก
4. แตะ/คลิกจุดต่อไปเพื่อสร้างช่วงถนน
5. สามารถแตะจุดต่อไปเรื่อย ๆ เพื่อทำทางเลี้ยวหลายช่วง
6. ถ้าจุดใหม่ไม่ได้อยู่แนวเดียวกัน ระบบจะสร้างช่วงหักมุมแบบ 90° ให้โดยอัตโนมัติ
7. กด **จบเส้นทาง** หรือกด Enter เมื่อต้องการบันทึกถนน

การวางถนนบนจุดเดียวกับถนนเดิมทำให้เกิด node ร่วม และการวางถนนตัดผ่านกันบนกริดจะกลายเป็นจุดร่วมของโครงข่าย

### Geometry และเส้นเลน

การวาดถนนถูกแยกจาก road data และใช้ centerline เดียวเป็นฐานของ geometry:

- ผิวถนนหลายชั้นพร้อมขอบทาง/เงาขอบ เพื่อให้เห็นเป็นพื้นถนนจริง
- ทางเลี้ยวใช้เส้นโค้งแบบ smooth corner แทนการหักเป็นมุมฉากแข็ง ๆ
- เส้นเลนถูก offset จาก centerline เดียวกัน จึงต่อเนื่องผ่านโค้ง
- ขอบเลนเป็นเส้นทึบ และเส้นแบ่งเลนภายในเป็นเส้นประ
- ถนนสวนทางใช้เส้นกลางสีเหลือง และถนน 4 เลนใช้เส้นกลางคู่
- ถนนทางเดียวมีลูกศรทิศทางแยกตามแต่ละเลน
- จุดแยกมี junction surface ของตัวเองเพื่อให้การเชื่อมหลายแขนกลืนเป็นผิวเดียว
- เส้นเลนจะไม่ถูกวาดทับบนพื้นที่ junction ทำให้ช่องทางข้ามแยกอ่านง่ายขึ้น

ทั้งหมดเป็นการวาดจาก road geometry เดียว ไม่ใช่การวาดเส้นถนนแต่ละชิ้นด้วยพิกัดแยกกัน

### Network topology สำหรับรถในอนาคต

ไฟล์ `road-network.js` สร้างเครือข่ายจาก road model ทุกครั้งที่แก้ไข:

- **nodes** — จุดพิกัดที่รถสามารถเข้า/ออกโครงข่ายได้
- **directed edges** — ช่วงถนนแบบมีทิศทาง
- ถนนสวนทางสร้าง edge ไปและกลับ
- ถนนทางเดียวสร้างเฉพาะ edge ตามทิศทาง
- ทุก edge มีจำนวนเลนสำหรับทิศทางนั้น
- **turns** — ความสัมพันธ์ระหว่าง edge ที่เข้าจุดเดียวกัน เช่น ตรง, ซ้าย, ขวา และกลับรถ
- **junctions** — จุดที่มีถนน 3 ทิศขึ้นไป หรือมีถนนหลายเส้นมาแชร์ node เดียวกัน

โครงสร้างนี้ตั้งใจวางไว้สำหรับขั้นถัดไป เช่น pathfinding, lane selection, traffic rules, signal priority, traffic lights, congestion และ vehicle routing โดยไม่ต้องรื้อระบบถนนเดิม

## การเก็บข้อมูลถนน

ถนนที่สร้างใน Prototype นี้เก็บใน `localStorage` ของ Browser เพื่อให้รีเฟรชหน้าแล้วถนนยังอยู่ โดยใช้ storage key แบบมี version:

`transport-project.roads.v2`

ข้อมูลถนนเก็บเป็นพิกัดกริดและชนิดถนน ไม่ผูกกับตำแหน่ง Pixel ของจอ ทำให้สามารถเรนเดอร์ใหม่เมื่อ Zoom, Browser Zoom, orientation หรือขนาดหน้าต่างเปลี่ยนได้

## การลบถนน

เลือก **ลบถนนทั้งเส้น** แล้วคลิก/แตะบน centerline ของถนน ระบบจะลบ road object ทั้งเส้นและสร้าง network ใหม่ทันที

## การควบคุม

Desktop:
- เลือก / เลื่อนแมพ: ลากเพื่อเลื่อน
- สร้างถนน: คลิกทีละจุด
- ลบถนน: คลิกบนถนน
- Mouse wheel: ซูม
- Enter: จบการสร้างถนน
- Escape: ยกเลิกจุดที่กำลังวาง

Touch:
- โหมดเลือก: ลากหนึ่งนิ้วเพื่อเลื่อน
- โหมดสร้างถนน: แตะทีละจุดเพื่อวางเส้น
- สองนิ้ว: pinch-to-zoom
- ปุ่ม + / − / ศูนย์ ใช้ควบคุมมุมมอง

1. ทำ terrain/tile data ให้เป็นข้อมูลจริงบน Infinite Grid
2. เพิ่ม road upgrade และกติกาการเชื่อมถนน
3. ทำ lane-level routing และกติกาการเลี้ยวให้ละเอียดขึ้น

5. เพิ่มระบบอาคาร/เมืองและจุดกำเนิด-ปลายทาง
6. เพิ่มรถ, pathfinding, traffic flow และ congestion
