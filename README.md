# Transport Project

โปรเจกต์นี้เริ่มใหม่จากศูนย์สำหรับสร้างเกมขนส่งบนเว็บ โดยพัฒนาบนเกมหลักบน `main` โดยตรง **ไม่มี workflow ที่บังคับให้ผู้ใช้ต้องเปิด Pull Request, merge หรือกดดำเนินการเอง**

## ระยะเริ่มต้น

- UI/UX หลักของเกม
- **แผนที่กริดไม่มีขอบเขต (Infinite Grid)** — ไม่มีการล็อกเป็น 120 × 80 หรือขนาดโลกตายตัว
- ระบบจะวาดเฉพาะช่องกริดที่อยู่ในจอ เพื่อให้ขยายพื้นที่ได้โดยไม่ต้องสร้างช่องทั้งหมดไว้ล่วงหน้า
- Responsive สำหรับมือถือ แท็บเล็ต และจอใหญ่ รวมถึงตอนผู้ใช้ย่อ/ขยาย Browser หรือเปลี่ยน orientation
- Layout ใช้พื้นที่ viewport จริงและซ่อน/ยุบส่วนที่ไม่จำเป็นเมื่อพื้นที่แคบ เพื่อไม่ให้ UI ล้นออกนอกจอ
- Canvas ปรับขนาดตาม viewport และรักษาตำแหน่งกล้องเมื่อ viewport เปลี่ยนจาก Browser Zoom, split-screen หรือการหมุนจอ
- Zoom 5%–300% โดยยึดตำแหน่งเมาส์
- ลากแผนที่, mouse wheel, touch drag และ pinch-to-zoom
- ปุ่มศูนย์กลางสำหรับกลับมาที่จุดกำเนิดของแผนที่
- เลือกช่องและอ่านพิกัดแบบจำนวนเต็มที่สามารถเป็นบวกหรือลบได้
- เปิด/ปิดเส้นกริดและกริดหลัก

## แนวคิดขนาดแมพ

แมพของเกม **ไม่ควรถูกจำกัดด้วยจำนวนช่องที่กำหนดไว้ล่วงหน้า** ในขั้นนี้จึงใช้พิกัดกริดแบบไม่จำกัดแทนการสร้างอาร์เรย์ 120 × 80

ตัวอย่าง:
- `X 0 · Y 0` อยู่บริเวณจุดกำเนิด
- สามารถลากไปทางขวา/ซ้าย/บน/ล่างได้ต่อเนื่อง
- พื้นที่นอกจอจะยังไม่มีการสร้าง DOM หรือ object จำนวนมหาศาล
- renderer คำนวณและวาดเฉพาะช่องที่มองเห็นใน viewport
- เส้นกริดหลักทุก 10 ช่องใช้เป็นเพียงตัวช่วยอ่านพื้นที่ ไม่ใช่ขอบเขตของโลก

ดังนั้นขนาดของโลกใน UI จะแสดงเป็น **ไม่จำกัด** และไม่มีกรอบสี่เหลี่ยมปิดล้อมแมพ

## การควบคุม

Desktop: ลากเพื่อเลื่อน · Mouse wheel เพื่อซูม · คลิกเพื่อเลือกช่อง  
Touch: ลากหนึ่งนิ้ว · pinch สองนิ้ว · แตะเพื่อเลือกช่อง

## แผนการพัฒนาหลังจากฐานนี้

1. ทำ UI + กล้อง + infinite grid ให้เสถียร
2. เพิ่มข้อมูลช่องและภูมิประเทศแบบสร้างเมื่อจำเป็น
3. เพิ่มเครื่องมือวาง/ลบพื้นที่
4. เพิ่มถนนและโครงข่ายขนส่ง
5. จึงค่อยเพิ่มเมือง ผู้โดยสาร เศรษฐกิจ และ simulation

**กติกาการทำงาน:** ทุกการเปลี่ยนแปลงต้องทำในเกมหลักบน `main` โดยตรง ไม่สร้างขั้นตอนแยกที่ทำให้ผู้ใช้ต้องไปกด merge หรือ PR เอง
